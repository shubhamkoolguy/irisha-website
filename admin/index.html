Checking your editor setup…

The sign-in button is not available because this editor has not been connected to your business’s GitHub repository and authentication service.

Next step: choose the GitHub repository that will store your website content. Its URL is needed to complete the connection.

What needs to be connected?
  1. Website content: replace the placeholder repository in admin/config.yml with your actual GitHub owner and repository name.
  2. Publishing: connect that repository to Cloudflare Pages using build command npm run build:pages and output directory dist.
  3. GitHub sign-in: configure the OAuth application and the hosting settings SITE_URL, GITHUB_REPO, GITHUB_CLIENT_ID and GITHUB_CLIENT_SECRET. Store the client secret in the hosting provider’s secret settings.
  4. CMS address: align the production domain, CMS configuration and OAuth callback. Open the connected production website’s /admin/ page to sign in.

This Sites review deployment does not automatically connect the business domain, GitHub sign-in or Cloudflare publishing.

Once the connection is complete, sign in with an authorised GitHub account to edit offers, prices, sacred circuits, fleet and homepage content.
